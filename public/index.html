LovePush

Простая личная кнопка любви для вас двоих. Один раз соединяете пару, потом отправляете пуш в один тап или через Команды на iPhone.

Только для вашей пары Пуши на iPhone Команды и ярлыки

Шаг 1

1. Создать приглашение

Делается один раз. Создай пару и отправь ссылку любимому человеку.

Шаг 2

2. Подключить устройство

На iPhone лучше сначала добавить сайт на экран «Домой», а уже потом подключать устройство.

Только для тебя. Если поле пустое, будет показываться её обычное имя.

Шаг 3

3. Отправить любовь

По умолчанию уйдёт простой пуш. Свой текст можно добавить по желанию.

Появится после регистрации устройства

Шаг 4

Как поставить на iPhone

  1. Открой страницу в Safari.
  2. Нажми «Поделиться» → «На экран Домой».
  3. Открой иконку с домашнего экрана.
  4. Для первого входа зарегистрируй устройство по ссылке-приглашению.
  5. Потом открывай иконку и жми большую кнопку отправки.

Для Команд на iPhone можно просто вставить короткую ссылку из блока выше в действие «Получить содержимое URL».
